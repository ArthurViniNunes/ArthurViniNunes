## About me

I am a Computer Science student at UFC and a Full Stack Developer interested in building reliable, clear and useful digital products.

I enjoy working across product, experience and engineering: understanding the problem, making thoughtful decisions and turning ideas into software people can actually use.

My main interests include:

- Full Stack development;
- software architecture;
- DevOps, cloud and automation;
- thoughtful user interfaces;
- well-documented and maintainable systems.

My main personal project is **Smash or Pass**, an application for discovering and sharing recipes.

## Featured project

### [Smash or Pass](https://github.com/ArthurViniNunes/smash-or-pass/)

An app for discovering, rating, and sharing recipes.

The project brings together:

- a web interface;
- business rules;
- authentication;
